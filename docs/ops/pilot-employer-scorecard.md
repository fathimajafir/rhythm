# Pilot employer scorecard

Use with **ADR-001**. Score each criterion 1–5, multiply by weight, sum.
**Proceed at ≥ 70/100 with no criterion scored 1.** Fill one sheet per employer;
keep every sheet — the rejected list is an asset for the next round.

## Disqualifiers (any one ends the conversation)

- [ ] Refuses cohort-minimum aggregates (k ≥ 10) or asks for individual drill-down
- [ ] Wants the app to report employees to managers
- [ ] Mandates activation ("everyone must use it") rather than offering it
- [ ] Cannot name who signs the DPA within two weeks of asking

## Reading the result

- **≥ 70, no 1s** → proceed to legal pre-read (ADR-001 step 4)
- **55–69** → fixable gaps only; re-score after one clarifying call, then decide
- **< 55, or any disqualifier** → park; revisit next cycle

## After selection

Start the DPA **the same week** (it is the critical path), book the stepped-wedge
department map, and record the cohort's language default so the locale work has a
target (design §0.4).
